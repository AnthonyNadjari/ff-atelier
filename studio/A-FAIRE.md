**La liste vit maintenant dans le tableau GitHub : https://github.com/users/AnthonyNadjari/projects/1**
(appli GitHub sur le téléphone : onglet Profil > Projects).

Une carte par tâche, trois colonnes : À faire, En cours, Fait. Champ « Qui » (Anthony, Associé, Les deux,
Claude) et « Thème » (1 Bloquant, 2 Site du studio, 3 Vendre, 4 Outils). On fait glisser la carte quand ça
avance, on commente dessous pour en parler. Claude peut aussi les créer et les fermer : lui dire « ajoute
une tâche… » ou « c'est fait ».
