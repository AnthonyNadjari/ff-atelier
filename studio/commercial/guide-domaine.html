Votre nom de domaine

L'adresse de votre site (par exemple fromagerie-ravanel.fr) est à vous. Nous l'achetons pour vous, à votre nom, et nous la payons d'avance pour dix ans : c'est compris dans le prix du site. Vous n'avez rien à acheter, rien à renouveler, aucun compte à créer.

Ce que nous faisons

  1. Vous choisissez l'adresse.Courte, sans accent, facile à dicter au téléphone : le nom de votre boutique, et la ville si le nom est commun. Le .fr suffit pour une clientèle française. Vous nous donnez deux ou trois formes dans l'ordre de préférence ; nous prenons la première libre.
  2. Nous l'enregistrons à votre nom chez OVHcloud,avec votre raison sociale, votre SIREN et votre adresse : vous en êtes le titulaire, pas nous. Dix ans payés d'avance, renouvellement automatique coupé : aucun prélèvement ne vous attend.
  3. Nous branchons le site dessus,le jour de la mise en ligne, une fois le solde réglé. Le certificat de sécurité (le cadenas) est automatique.
  4. Nous vous donnons la date d'expiration,dans dix ans, écrite sur la fiche « après la livraison ». Avant cette date, vous pourrez prolonger où vous voulez, ou nous demander de le faire au forfait.

Vous avez déjà un nom de domaine

Gardez-le, il reste chez votre fournisseur actuel et à votre nom. Dites-nous simplement lequel et chez qui (OVH, Ionos, Gandi…). Nous vous indiquerons la seule chose à modifier dans votre espace client, en deux clics et en partage d'écran si vous préférez. Si vous avez des adresses e-mail sur ce domaine, dites-le-nous avant : nous les préservons, rien ne s'arrête.

Ce qu'il faut savoir

Prix
Compris dans le prix du site. Aucune facture annuelle, ni de nous, ni d'OVHcloud.
Propriété
Le domaine est enregistré à votre nom. Nous ne possédons rien de ce qui est à vous : c'est écrit dans nos conditions.
Changer de prestataire un jour
Vous nous demandez le code de transfert de votre domaine : nous vous le remettons sous quinze jours, gratuitement. Le site vous est remis en fichiers.
Si nous arrêtons notre activité
Vous êtes prévenu trois mois avant, et vous recevez votre site complet, le code de transfert et une fiche pour l'héberger ailleurs gratuitement.
Adresses e-mail
Nous ne gérons pas de boîte mail. Une boîte de base est offerte par OVHcloud avec le domaine ; nous vous expliquons comment l'activer à votre nom si vous le souhaitez.
