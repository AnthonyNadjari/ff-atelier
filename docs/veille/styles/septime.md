## Le style en une phrase

Tout en machine à écrire, noir sur blanc, une photo noir et blanc très sombre et une carte blanche pour le nom.

- Titre : Prestige (graisse 300, interlignage à juger, casse none, interlettrage 0 em) ; libre : **spaceMono**.
- Texte : Prestige (graisse 400, interlignage 1.5) ; libre : **spaceMono**.
- Échelle (téléphone / ordinateur, px) : h1 téléphone 24 / ordinateur 20 ; h2 téléphone 14 / ordinateur 14 ; texte téléphone 15 / ordinateur 14.
- Prestige (machine à écrire) partout : Space Mono, la mono libre la plus proche d'une police de machine à écrire. Une seule famille, comme la source.
